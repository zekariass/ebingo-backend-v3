Frontend integration (Aggregator)

The game is embedded into the website via an iframe. The game occupies the allocated height, and if necessary,
allows scrolling the game inside the iframe.

1. URL Generation
For an authorized user, the URL for the iframe looks like this:
https://api.golden-eggs.games/api/aggregator/launch?aggregatorId=${aggregatorId}&subId=${subId}&gameMode=${gameMode}&currency=
${currency}&authToken=&{authToken}&lang=&{lang}&adaptive=${adaptive}&isDemoPlay=${isDemoPlay}&token=${token}&lobbyUrl={lobbyUrl}&brandName=${brandName}

To open demo mode, the URL for the iframe looks like this:
https://api.golden-eggs.games/api/aggregator/launch?aggregatorId=${aggregatorId}&subId=${subId}&gameMode=${gameMode}&currency=
USD&authToken=&{authToken}&lang=&{lang}&adaptive=${adaptive}&isDemoPlay=true&token=${token}&lobbyUrl={lobbyUrl}&brandName=${brandName}

2. Required Attributes for the iframe Tag
For the correct functioning of all game features, the following attributes must be added to the iframe tag:
scrolling="yes" allow="autoplay" allowfullscreen=""

Thus, the iframe tag should look like this:
<iframe scrolling="yes" allow="autoplay" allowfullscreen="" src="${url}"

3. Supported Languages
If a language code is not supported, English will be used by default.

4. Supported Currencies and Rounding Rules
. All fiat currency values are rounded to 2 decimal places
. All cryptocurrency values are rounded to 9 decimal places


Fiat Currencies: ETB
Cryptocurrencies: ADA, BCH, BNB, BTC, BUSD, CSC, DASH, DOGE, ETC, ETH, LTC, TRX, USDC, USDT, XMR, XRP,ZEC, TON , SHIB , XLM


5. Parameter Descriptions
| **Field Name**  | **Field Type**    | **Description**                                                                                                     |
| --------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------- |
| gameMode        | String            | Game ID in the provider system                                                                                      |
| aggregatorId    | UUID              | Platform ID in the supply system with the aggregator type                                                           |
| currency        | String            | User's currency                                                                                                     |
| authToken       | String            | User authentication token                                                                                           |
| lang            | String            | Code of the desired interface language                                                                              |
| themeId         | UUID              | Branding theme ID. Defaults to the platform ID in the provider system                                               |
| lobbyUrl        | String            | URL for the “back to home” button in the game UI. Clicking the button redirects to the page specified in `lobbyUrl` |
| subId           | String            | Brand ID (brand name)                                                                                               |
| isDemoPlay      | Boolean           | Game in demo mode                                                                                                   |
| token           | String            | Token to validate `subId`                                                                                           |
| brandName       | String (optional) | Brand name                                                                                                          |
| userCountryCode | String            | Important: User’s country code (ISO 3166-1 alpha-2, e.g., TR). Used to replace the domain in case of blocking       |
