Bonus system (Aggregator)

1. Authorization
To perform an action, you must include the X-REQUEST-SIGN header, which supports the signature.
The generation of the signature is described using the HMAC-SHA256 algorithm. This algorithm includes:

** operator_id: as the operation ID.
** signature_key: provided by the Provider during registration.

Example:
Operator ID (subOperatorId) (description of generation in number 7 below): 6295c404-e633-48cc-ae14-8ca0880d55d4

2.Creating a bonus
To create a bonus, you should send a POST request to the URL:

https://api.golden-eggs.games/api/operator/v1/bonuses/:operatorId

Query string parameters:
| **Field name** | **Field type** | **Description**              |
| -------------- | -------------- | ---------------------------- |
| operatorId     | UUID           | Sub-operator ID from `subId` |

Request body parameters:
| **Field Name**                         | **Type** | **Description**                                                                  |
| -------------------------------------- | -------- | -------------------------------------------------------------------------------- |
| userId                                 | String   | The user's unique ID in your system                                              |
| bonusId                                | UUID     | The bonus ID (unique for each assigned user)                                     |
| gameMode* (deprecated – use gameModes) | String   | The game mode code                                                               |
| gameModes                              | String[] | The game modes code                                                              |
| currency                               | String   | The currency (e.g., USD, BTC)                                                    |
| type                                   | String   | The bonus type: FREEBET                                                          |
| expiresAt                              | String   | Expiration date of the bonus. Format: ISO8601 (e.g., `2024-07-16T10:03:49.101Z`) |
| freebetConfig                          | Object   | Configuration for bonuses of type FREEBET                                        |

freebetConfig Parameters:
| **Field Name**       | **Type** | **Description**                                                                                       |
| -------------------- | -------- | ----------------------------------------------------------------------------------------------------- |
| count                | String   | The total number of bonuses                                                                           |
| chickenRoadConfig    | Object   | Bonus and game configuration for Chicken Road (chicken-road, chicken-road-92, chicken-road-97)        |
| luckyMinesConfig     | Object   | Configuration for the "LuckyMines" game mode                                                          |
| chickenRoadTwoConfig | Object   | Bonus and game configuration for Chicken Road 2 (chicken-road-two)                                    |
| plinko1000Config     | Object   | Plinko 1000 bonus and game configuration (plinko, plinko-v2, plinko-v3)                               |
| forestFortuneConfig  | Object   | Forest Fortune bonus and game configuration (forest-fortune-v1, forest-fortune-v2, forest-fortune-v3) |


chickenRoadConfig Parameters:
| **Field Name** | **Type** | **Description**                                                                               |
| -------------- | -------- | --------------------------------------------------------------------------------------------- |
| betAmount      | String   | Bet amount for the game                                                                       |
| difficulty     | String   | Difficulty level. Options: EASY, MEDIUM, HARD, DAREDEVIL. Optional parameter; default is EASY |


luckyMinesConfig Parameters:
| **Field Name** | **Type** | **Description**                  |
| -------------- | -------- | -------------------------------- |
| betAmount      | String   | Bet amount for the game          |
| minesCount     | String   | The number of mines. Range: 2–24 |


chickenRoadTwoConfig Parameters:
| **Field Name** | **Type** | **Description**                                                                               |
| -------------- | -------- | --------------------------------------------------------------------------------------------- |
| betAmount      | String   | Bet in game                                                                                   |
| difficulty     | String   | Difficulty level. Options: EASY, MEDIUM, HARD, DAREDEVIL. Optional parameter; default is EASY |


plinko1000Config parameters:
| **Field Name** | **Type** | **Description**                                                           |
| -------------- | -------- | ------------------------------------------------------------------------- |
| betAmount      | String   | Bet in game                                                               |
| risk           | String   | Risk level. One of: LOW, MEDIUM, HIGH. Optional parameter; default is LOW |


forestFortuneConfig parameters:
| **Field Name** | **Type** | **Description**                                                              |
| -------------- | -------- | ---------------------------------------------------------------------------- |
| betAmount      | String   | Bet in game                                                                  |
| risk           | String   | Risk level. One of: LOW, MEDIUM, HIGH. Optional parameter; default is MEDIUM |


Example Request body parameters:
{
  "userId": "21704",
  "bonusId": "8eb034e0-ca4c-44e3-a9a4-692d71b261fe",
  "gameModes": ["lucky-mines"],
  "currency": "USD",
  "expiresAt": "2024-07-17T13:31:20.873Z",
  "type": "FREEBET",
  "freebetConfig": {
    "count": "10",
    "luckyMinesConfig": {
      "betAmount": "1000",

Expected responce:
{
  "status": true
}

Where:
| **Field Name** | **Type** | **Description**                           |
| -------------- | -------- | ----------------------------------------- |
| status         | Boolean  | True if the bonus is successfully created |


3. Fetching Bonus Data
To retrieve data about bonuses, a GET request should be sent to URL:
https://api.golden-eggs.games/api/operator/v1/bonuses/:operatorId


Query string parameters:
| **Field Name** | **Type** | **Description**                        |
| -------------- | -------- | -------------------------------------- |
| operatorId     | UUID     | The unique identifier for the operator |


Request body parameters:
| **Field Name**                  | **Type** | **Description**                           |
| ------------------------------- | -------- | ----------------------------------------- |
| filter[userId]                  | String   | Filter by user ID                         |
| filter[gameModes]               | String   | Filter by game mode                       |
| filter[currency[]]              | String[] | Filter by currency                        |
| filter[status]                  | String[] | Filter by bonus status (e.g., ACTIVE)     |
| filter[betAmountFrom]           | String   | Minimum bet amount                        |
| filter[betAmountTo]             | String   | Maximum bet amount                        |
| filter[expiresAtFrom]           | String   | Filter: expiration date FROM              |
| filter[expiresAtTo]             | String   | Filter: expiration date TO                |
| filter[expiresWhenActiveAtFrom] | String   | Filter: date of end of wagering time FROM |
| filter[expiresWhenActiveAtTo]   | String   | Filter: end date of play time TO          |
| pageable[page]                  | Int      | Page number                               |
| pageable[limit]                 | Int      | Number of results per page                |


Bonus Statuses:
| **Status Name**     | **Description**                                                   |
| ------------------- | ----------------------------------------------------------------- |
| CREATED             | Bonus is created but not yet activated                            |
| ACTIVE              | Bonus is active and usable                                        |
| PENDING_COMPLETE    | Bonus is awaiting completion                                      |
| COMPLETED           | Bonus is completed successfully                                   |
| EXPIRED             | Bonus has expired                                                 |
| CANCELLED           | Bonus is cancelled by the operator                                |
| EXPIRED_WHEN_ACTIVE | Bonus expired after wagering started (time of first bet + 7 days) |

5. Cancelling a Bonus
To cancel a bonus, send a DELETE request to the following URL:
https://api.golden-eggs.games/api/operator/v1/bonuses/:operatorId/:bonus

Query Parameters:
| **Field Name** | **Type** | **Description**           |
| -------------- | -------- | ------------------------- |
| operatorId     | UUID     | The operator's ID (yours) |
| bonusId        | UUID     | The bonus ID              |


Expected Response:
{
  "status": true
}

Where:
| **Field Name** | **Type** | **Description**                              |
| -------------- | -------- | -------------------------------------------- |
| status         | Boolean  | True if the bonus was successfully cancelled |


6. Webhooks
6.1 Bonus Completion by Player
This request is sent when the player's bonus is closed. The winSum value in the request body reflects the total
winnings from all bets, including the bet amount.

Example:
** A player received 5 free bets worth 100 USD each.
** Lost 4 free bets and won 1, with a total winnings amount of 150 USD.
** winSum:
    *** 4 x 0 USD = 0 USD
    *** 1 x 150 USD = 150 USD
    *** 0 + 150 = 150 USD
** Total winnings 150 USD

Incoming Request:
{
  "action": "bonus-complete",
  "token": "SessionToken",
  "gameMode": "crash",
  "data": {
    "bonusId": "22166608-be33-438a-82d4-844c3b788d2e",
    "currency": "USD",
    "winSum": "150",
    "operator": "OperatorId",
    "userId": "1",
    "transactionId": "22166608-be33-438a-82d4-844c3b788d2e"
  }
}


Expected Response:
{
  "code": "OK",
  "balance": "1150",
  "hideFromStat": true
}


6.2 Bonus Expired Due to Active Period End
This request is sent when the player's bonus is closed because it was not used within the allowed period
(expiresWhenActiveAt). In this case, the winSum is always sent as 0.

Incoming Request:
{
  "action": "bonus-expired-when-active",
  "token": "SessionToken",
  "gameMode": "crash",
  "data": {
    "bonusId": "22166608-be33-438a-82d4-844c3b788d2e",
    "currency": "USD",
    "winSum": "0",
    "operator": "OperatorId",
    "userId": "1",
    "transactionId": "22166608-be33-438a-82d4-844c3b788d2e"
  }
}

Expected Response:
{
  "code": "OK",
  "balance": "100",
  "hideFromStat": true // (optional) Whether to hide the player from statistics
}


7. Generate subOperatorId for subId
        import { v4 } from 'uuid';
        import crypto from 'node:crypto';

        export function getSubOperatorId(aggregatorId: string, subId: string) {
          return generateUUIDv4FromString(`${aggregatorId}:${subId}`);
        }

        export function generateUUIDv4FromString(inputString: string) {
          const seed = crypto.createHash('md5').update(inputString).digest();
          return v4({ random: seed });
        }
